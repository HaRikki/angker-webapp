HOW TO DEPLOY (important!):

Method A — using main.py (recommended on VPS/Apsara):
1. Stop the running app (Ctrl+C or kill the process)
2. Upload THIS whole folder (or at least main.py) over the old one
3. DELETE these so force re-extract + rebuild:
     rm -rf angker-ready/.zip-applied angker-ready/.next
4. Run:  python3 main.py
5. Wait for "npm run build" to finish (first time may take 1–3 min)
6. Open Mini App → hard refresh:
     Telegram: close mini app completely, reopen
     Or clear cache / open in external browser once

Method B — only replace source files:
1. Copy files from angker-ready/ over your existing angker-ready/
2. rm -rf angker-ready/.next
3. cd angker-ready && npm run build && npm start
   (or restart main.py)

If UI still old after rebuild → Telegram is caching.
Close the mini app from recent apps, reopen from the bot menu.
